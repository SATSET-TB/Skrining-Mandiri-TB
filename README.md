# skrining-mandiri-TB
SATSET-TB adalah website skrining mandiri Tuberkulosis yang dapat diakses gratis lewat HP atau komputer. Cukup menjawab beberapa pertanyaan sederhana, pengguna langsung mengetahui tingkat risikonya beserta saran tindak lanjut. Data tidak disimpan. Hasil skrining bukan diagnosis dan tidak menggantikan pemeriksaan tenaga kesehatan.
